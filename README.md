# Ejercicios de char en C

Este proyecto contiene cinco ejercicios básicos del lenguaje C para practicar el uso de caracteres (`char`).

## Ejercicios

1. `ejercicio1_ascii.c`: muestra el valor ASCII de un carácter.
2. `ejercicio2_vocal.c`: identifica si un carácter es una vocal o consonante.
3. `ejercicio3_mayuscula.c`: convierte una letra minúscula en mayúscula.
4. `ejercicio4_contar_letra.c`: cuenta cuántas veces aparece una letra en una palabra.
5. `ejercicio5_digito.c`: identifica si un carácter es un dígito numérico.

## Requisitos

- Tener instalado GCC.
- Tener una terminal disponible.

## Cómo compilar y ejecutar

Ejemplo para el primer ejercicio:

```bash
gcc ejercicio1_ascii.c -o ejercicio1_ascii
./ejercicio1_ascii
